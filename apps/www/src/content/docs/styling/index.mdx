Every file the scaffolder wrote is yours to change. Start with how that works, then pick what you're changing. The [component catalog](/components) shows every component you can add.

- [How customization works](/styling/how-customization-works): which files are yours, which are the framework's, and how to take updates.
- [Add components and features](/styling/add-components): install a component or a feature with `nimbus-docs add`.
- [Branding](/styling/branding): your logo, name, favicon and colours.
- [Theme and tokens](/styling/theme-and-tokens): the design tokens behind colour, type and spacing.
- [Layouts](/styling/layouts): the page shells, and turning columns off.
- [Custom components](/styling/custom-components): write your own component and use it in MDX.
