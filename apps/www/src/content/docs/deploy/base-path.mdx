Set Astro's `base` to publish the site under a path. Every page, Markdown version and `llms.txt` moves under it.

## Steps

<Steps>
  <Step title="Set the base">
    In `astro.config.ts`:

    ```ts title="astro.config.ts" {2}
    export default defineConfig({
      base: "/docs",
      // …
    });
    ```
  </Step>
  <Step title="Decide who owns the domain's discovery files">
    Agent discovery files live at the domain root, not under `/docs`. If another site owns the domain, set `agents: { discovery: false }` in the Nimbus config. Otherwise, see [Under a base path](/ai/agent-discovery#under-a-base-path) for where they go.
  </Step>
  <Step title="Build and deploy">
    <PackageManagers pkg="build" type="run" />

    With the Cloudflare adapter and static output, deploy with `wrangler deploy --assets ./dist/client`.
  </Step>
</Steps>

## Verify

Open `https://example.com/docs/` and `https://example.com/docs/llms.txt`. Both load, and links in `llms.txt` start with `/docs/`.
