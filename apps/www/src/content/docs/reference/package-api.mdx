The starter's routes and layouts call these helpers, and so will yours when you customize them. This page covers the ones customization needs; each package entry exports more, and its TypeScript types document every export. The package follows semver, and `nimbus-docs migrate` handles breaking changes ([Upgrading](/publish/upgrading)).

## Page routes

From `@cloudflare/nimbus-docs`. The starter's `src/pages/[...slug].astro` uses them.

| Helper | What it does |
| --- | --- |
| `getDocsStaticPaths` | `getStaticPaths` for a docs collection: one path per page. |
| `getDocsPage(Astro)` | The page's entry, rendered `Content` and headings, or a `404` `Response` for a request-rendered miss. |
| `getRouteFlags(entry)` | Whether the page shows the sidebar and the table of contents, after frontmatter and config. |
| `entryRouteKey(id)` | The URL segment for an entry id, with `index` collapsed. |

## Navigation

| Helper | What it does |
| --- | --- |
| `getSidebar(slug, { collection })` | The sidebar tree for a page, with the current page and its groups marked. |
| `getSidebarSections(slug, { collection })` | The site's top-level sections, for the header's section tabs. |
| `getPrevNext(slug, { sidebarTree, overrides })` | The previous and next pages in sidebar order, after `prev` and `next` frontmatter. |
| `getBreadcrumbs(slug)` | The trail of groups above a page. |
| `getTOC(headings, config)` | The table of contents for a page, from its headings and `tableOfContents` settings. |

## Page details

| Helper | What it does |
| --- | --- |
| `getEditUrl(entry)` | The page's edit link, from `editPattern`, or `undefined`. |
| `getLastUpdated(entry)` | The page's last git commit date, or `undefined` when git can't say. |
| `getVersionStatus(key)` | Whether a version is current, deprecated or hidden, for banners. |
| `getCollectionLlmsUrl(collection)` | The `llms.txt` that indexes a collection. |

## URLs

| Helper | What it does |
| --- | --- |
| `withBase(path, base)` | Adds Astro's `base` to a site path, once. |
| `stripBase(pathname, base)` | Removes it. |

## API reference pages

From `@cloudflare/nimbus-docs/runtime`. [OpenAPI reference pages](/writing/openapi) shows them in the API route.

| Helper | What it does |
| --- | --- |
| `getApiStaticPaths(collection)` | `getStaticPaths` for an API reference route, across its versions. |
| `getApiRoute(Astro)` | The page and sidebar for an API route, or a redirect or `404` `Response`. |
| `getApiRoot(Astro, { collection, version })` | A version's root page, with its index of every endpoint, from any route. |
| `getApiVersions(collection)` | The versions of an API, for a picker. |

## Collections

From `@cloudflare/nimbus-docs/content`, in `src/content.config.ts`.

| Helper | What it does |
| --- | --- |
| `docsCollection(options)` | A docs collection; `schemaFields` adds frontmatter fields. |
| `partialsCollection(options)` | The reusable snippets that `<Render>` includes. |
| `componentsCollection(options)` | Component pages, like the [component catalog](/components). |
| `apiCollection(options)` | The pages generated from an OpenAPI spec. |

## Behaviour in the browser

From `@cloudflare/nimbus-docs/client`, in component scripts.

| Helper | What it does |
| --- | --- |
| `mount(selector, init)` | Runs `init` for every matching element on each page, including after client-side navigation, and its cleanup when the page goes. See [Custom components](/styling/custom-components). |
| `initTabs(config)` | Tab-list keyboard and selection behaviour. |
| `makeDisclosure(options)` | Open-and-close behaviour for a disclosure. |

## Markdown plugins

From `@cloudflare/nimbus-docs/markdown`, in `markdown.hastPlugins` in the integration options. See [Markdown and MDX](/writing/markdown-and-mdx).

| Plugin | What it does |
| --- | --- |
| `tableScroll()` | Wraps wide tables so they scroll instead of overflowing. |
| `externalLinks(options)` | Opens links to other sites in a new tab, with an arrow after the text. |
| `titleFigure(options)` | Turns an image with a title into a figure with a caption. |
| `math(options)` | Renders math as MathML at build time; turn on `features: { math: true }` too. |
